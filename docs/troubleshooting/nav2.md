# Nav2 Troubleshooting

This page collects navigation runtime issues and debugging steps.

## Outline

1. Nav2 starts but the robot does not move.
2. RViz goal is accepted but no command is published.
3. `cmd_vel` is published but the chassis does not move.
4. Local path oscillates.
5. Robot drives too slowly.
6. Turning fails or is too wide.
7. Costmap obstacles remain after moving away.
8. AMCL localization drifts.
9. Recovery behavior is not suitable for Ackermann steering.
