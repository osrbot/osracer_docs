# Roadmap

This roadmap turns known internal issues into public development directions.

## Short term

- Document Jetson Orin Nano setup.
- Document Nav2 speed optimization.
- Improve debugging guides.
- Document vehicle profiles and footprints.
- Document UDEV fixes.

## Mid term

- Add chassis driver reconnect behavior.
- Add serial heartbeat and status reporting.
- Add ROS diagnostics topics.
- Improve multi-vehicle profile management.

## Long term

- Explore MAVLink support.
- Define a cleaner chassis communication abstraction.
- Add automated bringup self-checks.
- Add link checking and preview deployments for docs.
