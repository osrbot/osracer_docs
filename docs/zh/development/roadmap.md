# Roadmap

本 Roadmap 将内部已知问题整理为公开开发方向。

## 短期

- 文档化 Jetson Orin Nano 安装。
- 文档化 Nav2 导航提速优化。
- 完善调试指南。
- 文档化车型 profile 和 footprint。
- 文档化 UDEV 修复。

## 中期

- 在客户工具中更清晰地展示底盘重连状态。
- 将底盘状态接入 ROS diagnostics topic。
- 完善多车型 profile 管理。

## 长期

- 探索 MAVLink 支持。
- 定义更清晰的底盘通信抽象。
- 增加自动 bringup self-check。
- 为文档增加链接检查和 PR 预览部署。
