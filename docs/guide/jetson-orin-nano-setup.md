# Jetson Orin Nano Setup

This page turns the internal installation notes into a reproducible public setup guide.

## Scope

- Jetson Orin Nano
- JetPack 6.2.1
- Ubuntu 22.04.5
- ROS 2 Humble

## Outline

1. Prepare the system.
2. Install ROS 2 Humble.
3. Install OSRacer dependencies.
4. Build `osracer_ws`.
5. Configure user permissions.
6. Verify bringup and debug tools.

## Notes

Internal remote access credentials and machine-specific secrets must not be published in this page.
